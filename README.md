# 聚能客户标记管理

基于高德地图的客户标记管理系统（单文件应用）。

## 功能
- 地图上添加/管理客户标记（按状态着色：已成交/有意向/咨询过）
- 客户信息管理：姓名/电话/地址固定条目 + 自定义条目、拜访记录、客户标签
- 导入/导出 Excel 客户数据（导出统一：姓名、电话、状态、地址、其他备注）
- 标记聚合 / 热力图 / 统计报表 / 多客户路线规划
- 手机导航、跟进提醒、批量操作、回收站恢复、一键备份
- 数据保存在浏览器本地（localStorage）

## 使用
直接访问本页面即可使用。首次使用请在右上角「设置」中填写高德 Web端(JS API) Key。

## 说明
- 客户数据存储在各用户自己的浏览器中，不同设备数据相互独立。
