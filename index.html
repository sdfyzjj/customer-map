管理员配置

本工具基于高德地图 JS API，需要先申请开发者 Key（免费）。
申请地址：console.amap.com → 应用管理 → 创建应用 → 添加 Key，服务平台选择「Web端(JS API)」。

上传客户数据到云端时使用此 Token；普通成员无需填写，在「云端同步」中输入共享密码即可上传 / 下载。

由管理员统一设置并告知团队成员；此密码用于加密云端客户数据，不会随数据同步上传，请线下告知成员。修改后点「确认」生效。

设置后云端数据升级为「双钥匙」：输入团队密码或超级密码都能上传 / 下载；即使团队密码被修改或遗忘，超级密码始终有效。修改后点「确认」生效。

上传 = 用本机客户数据整体覆盖云端（管理员权限）；下载 = 从云端合并拉取。

云端同步（多用户共享）

成员模式：仅上传 / 下载带自己标签的客户（无标签公共客户可下载共享）。管理员全量上传 / 下载请用「设置 → 管理员配置」。
